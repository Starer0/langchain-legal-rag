# V12.9：React 聊天工作区

原静态页面的大标题、整体滚动、侧栏溢出和中文输入提交问题影响使用。本步建立独立 React + TypeScript + Vite 前端，保留 FastAPI、PostgreSQL、服务器认证、资料权限及请求/RAG日志。

工作区提供紧凑标题、独立滚动的侧栏和消息区、固定输入区、移动抽屉、登录、聊天新建/重命名/删除、SSE进度、来源展开及错误请求编号。中文组合输入不会触发发送；阅读旧内容时不会强制跳至底部。移动抽屉与对话框管理键盘焦点和背景 inert，短视口登录页可实际滚动访问按钮。

`frontend/src/useChat.ts` 管理账号版本、会话选择和操作锁；身份变化清空私人界面，旧异步结果不能覆盖新账号。历史读取失败进入错误状态，不能继续发送。删除当前聊天立即清除其发送目标，即使列表刷新失败也不会向已删除聊天发送。完成事件后的连接异常保留已保存答案，避免把已完成问题恢复为重试草稿。

`web_app.py` 根据 `WEB_FRONTEND=react` 提供 `frontend/dist/index.html` 与 `/assets`，首页 no-store，构建缺失明确失败。默认 legacy 兼容原测试和静态页面。源文件、凭据和服务器日志不通过新静态目录暴露。构建与本地运行说明见 frontend/README.md。

## 代理验证（2026-10-04）

- 282 项 Python 测试通过，包含真实临时 PostgreSQL schema；未变更生产聊天/索引。pytest 有两项依赖弃用提示与一项 Windows asyncio 测试清理警告，无失败，具体日志本地 logs/react-full-tests.txt。
- 23 项 React 测试、11 项原 Node 行为测试、类型检查及生产构建通过。
- 5 项实际 Chrome 浏览器夹具测试通过：桌面登录/CRUD/来源/账号隔离，手机抽屉/输入法/固定输入区，失败流回滚，平板长历史独立滚动，375×400 短视口真实滚轮登录。
- 独立复查发现的三个控制器边界与短视口登录问题均已用失败测试复现、修复并复查关闭。
- 本地 WEB_FRONTEND 已切换 react，重启原 8001 服务。真实三个账号 login/me/list/logout 与退出401核验通过；真实 Chrome 使用 demo_ab 登录、读取现有聊天、退出通过。没有创建测试聊天或调用远程模型。

以上是代理验证，尚未记录用户对新 React 界面的亲自验收或实现原理理解。

## 保留边界

历史消息 API 只有 role/content，刷新后的来源附件尚未持久化；本步不扩展该数据模型。不新增后台、上传、日志查看界面、长期记忆、LangGraph持久恢复、重连、自动重试或副作用去重。后端仍执行已有授权规则，新界面没有成为权限边界。
