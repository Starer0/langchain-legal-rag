# 刷新后继续生成（用户已批准范围）

问题：SSE 请求拥有计算过程，刷新就断开。目标：后台任务拥有计算，网页只提交和观察。

独立 generation_tasks 表持久保存问题、所属用户/对话、提交键、运行状态、阶段、累计回答、来源、错误编号和时间。完成事务同时保存完整问答、来源和任务完成状态；半成品仅在任务中，不注入后续模型历史。

FastAPI 接受任务后由有容量限制的本进程后台线程执行。提交键和每用户最多一项运行任务由数据库约束保证，刷新查询原任务，不重跑模型。所有查询与提交按服务端登录身份校验。保留原 SSE 接口兼容旧页面；React 改用任务提交与短间隔查询，支持恢复临时问题、部分回答、侧栏转圈和后台浏览。

生产第一版只支持单个 Uvicorn 进程；后端启动时将遗留 running 标为 interrupted，提示重新发送，不自动续跑。关闭浏览器不取消任务，沿用生成期间禁用退出和对话修改的界面规则；若会话失效，停止观察，任务仍独立运行。后台任务日志用独立任务编号关联原提交编号，不把 HTTP 接受任务记成生成成功。

验证：阻塞假模型创建任务，刷新重新查询，释放后保存一次；提交去重、用户隔离、失败、启动中断、历史来源、前端刷新及切换、完整回归。生产数据库先备份再显式增量迁移。
