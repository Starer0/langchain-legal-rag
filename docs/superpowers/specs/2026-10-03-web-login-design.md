# V12 网页登录设计

用户已批准接入示例账户的网页登录、退出、3 天滑动会话和新对话账户归属；网页保持现有 HTML / JS，旧匿名记录不自动分配。实际 RAG 等级权限、React 和图任务恢复继续后续实施。

## 会话与归属

新增 login_sessions：随机登录 token 的 SHA-256 摘要、用户外键、随机 CSRF token、创建 / 最后活动 / 到期时间（UTC timestamptz）。Cookie legal_rag_auth 仅含随机 token，HttpOnly、SameSite=Lax，Secure 随已有 HTTPS 配置；Max-Age 和 Expires 对应 3 天。到期检查先于续期；过期、退出、停用或未知凭据拒绝，退出删除服务端记录。

conversations 新增可空 user_id 外键，session_id 改可空，CHECK 要求二者恰有一个。已有行仍保留原 session_id 和全部内容，新账号对话只写 user_id。共享存储实现按受控 owner 列检查归属，不信任浏览器提交的用户 ID。新登录会话不改变对话归属，所以另一浏览器登录同账号能访问同一历史；同账号多个浏览器的登录会话独立。

## 入口

POST /api/auth/login 接收用户名和密码并设 Cookie，GET /api/auth/me 返回当前公开用户信息、CSRF token 与到期时间，POST /api/auth/logout 撤销并清除 Cookie。认证失败统一提示，不回显密码；登录格式错误也使用安全响应。登录请求按真实连接 IP 在本进程限速（20 次 / 5 分钟），不信任自报代理地址。

产品默认应用强制保护所有 /api/conversations 及其子路径；匿名 Cookie 不能充当登录。显式注入 create_app 的原匿名模式与显式 SQLite 路径只保留本地测试 / 调试兼容，正常网页无运行时匿名降级开关。生产默认应用在 lifespan 初始化账号会话与用户存储，缺少 PostgreSQL / 显式迁移时启动失败。

认证中间件独立于流式 RAG，先检查 token、用户状态和变更请求 CSRF / Origin。只在身份查询和合法业务 2xx 响应时续期并重设 Cookie；静态、页面文件、非法请求、拒绝访问和后台定时均不续期。生成中的请求仍按请求开始时认证，退出不自动实现任务取消 / 恢复。

密码不进日志、URL 或本地存储；Cookie 和 CSRF 不进请求日志。认证与对话 JSON / SSE 响应禁止缓存；Origin 和 Fetch Metadata 检查配合 CSRF 自定义请求头，SameSite 不单独充当保护。

## 页面与验证

初始隐藏聊天内容，先查身份；未登录显示有标签的用户名 / 密码表单，密码可粘贴和自动填充。成功显示用户名、退出按钮和聊天；401 清空旧用户界面并回登录，登录错误就近显示。退出生成时不可点击，退出后清空列表、消息、输入和弹窗。页面显示 / 恢复时查询身份，不做定时保活。

真实 PostgreSQL 临时 schema 测试覆盖 Cookie 属性、错误密码、到期边界、静态不续期、有效请求续期、撤销 / 停用、跨浏览器同账号、跨账号资源拒绝、旧匿名不迁入、CSRF、限速、安全错误和日志。Node 行为测试及浏览器验收覆盖登录、退出、到期回登录、切换用户清理内容。完整回归和独立审查后备份 public，显式添加会话结构与用户归属列；保留原聊天并安全重启本机现有网页。
