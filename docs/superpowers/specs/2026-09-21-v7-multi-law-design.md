# V7：多法律知识库与 Metadata Filter

已确认范围：三部法律统一入库；普通问题默认查全库；明确法律名称和法条号时由服务端过滤；不增加 LLM 选库调用。保留 V6 的最近四轮历史、单查询 Rewrite、Chroma Top 8、Reranker Top 4。

## 导入与身份

- 用 `data/laws.json` 登记 law_id、law_name、版本施行日期、效力状态、来源网址、PDF 文件名、法条总数。目录描述的是人工核对的版本快照，不代表自动法律效力裁决。
- 每份 PDF 分别清洗页码、重复页眉和末尾“文档信息”；按章、条解析，记录真实 PDF 页码。不得把不同法律拼接后切分。
- 校验法条编号从 1 连续到登记总数；拒绝缺条、重复、空内容和未登记 PDF。每条保留 law_id、law_name、article、chapter、version、effective_date、status、source_file、source_url。
- 同号法条依靠 law_id + version + article 唯一标识。使用文件哈希、目录配置、切分版本和 Embedding 配置生成索引指纹。
- `python main.py --ingest` 显式导入。新建 `chroma_legal_db` 中的指纹集合，完整导入成功后原子更新 manifest。重复导入不重复向量化；改动内容生成新集合，保留旧库可回退。
- 问答启动检查 manifest/指纹/数量，未构建或内容变化时提示重新导入；不在每次启动重新解析 PDF。

## 检索与回答

- 默认检索全部现行登记法律。明确已知法律名称时过滤 law_id；单部法律明确单个法条号时同时过滤 article。多法律比较保留多部法律范围。
- 原始问题明确指定的法律优先于 Rewrite；无明确范围时可从独立检索问题恢复历史范围。Rewrite 提示词要求保留法律名与条号，不自行补造范围。
- 显式范围无结果时说明资料不足，不静默扩大范围。用户无需选择知识库。自动识别不是一般法律主题分类器，暂不做跨法律冲突判定。
- sources、candidates、CLI 和回答引用均保留法律名称与条号。历史字符串链输入仍可运行。

## 评测与完成条件

- 旧题和 V6 结果保留；新建 V7 题，使用 law_id + article 判断命中，空预期不算命中。
- 对相同问题比较全库检索和 metadata 过滤，记录实际过滤条件、候选/来源命中、改写问题、耗时及索引指纹。
- 回归测试覆盖同号法条、跨页、附录污染、重跑导入、失败不发布、改动检测、指定范围和多轮功能。
- 首次真实导入完成，并完成真实检索、重排及回答抽查。评测统计不等于法律意见正确率。
- 在当前主工作目录实现；根目录仅新增一个知识库模块，入口仍为 main.py。新 PDF、目录、实现、测试、评测摘要提交 Git；.env、向量索引及完整运行结果不提交。
