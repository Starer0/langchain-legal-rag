# React Web Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development and scoped review; independent UI and controller tasks may run in parallel.

**Goal:** Replace the current user-facing chat with the approved React workspace while retaining verified backend behavior.

**Architecture:** `frontend/` contains React/TypeScript/Vite, pure presentation components, and a request-aware controller hook. Existing safe auth/Markdown modules are imported and bundled. FastAPI serves the selected frontend build and assets on the same origin.

**Tech Stack:** React, TypeScript, Vite, CSS variables, Lucide SVG, Vitest/Testing Library, Playwright for browser checks.

**Spec:** ../specs/2026-10-04-react-web-design.md

## Global Constraints

- Preserve all existing login, CRUD, SSE, request ID and backend permission behavior.
- No remote model calls for agent verification; use test fixtures for full browser flows.
- No new admin / logs / upload / memory / retry / recovery features.
- Reuse current checkout containing uncommitted V12 dependencies. No commits/push; preserve unrelated work and ignored HANDOFF.
- No token/password persistence in browser storage; history sources remain absent after refresh under existing API.
