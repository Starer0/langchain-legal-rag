# V7 证据合并独立题集：预注册评测方案

在看到本题集的任何模型输出前，固定 `evals/composite_merge_holdout_cases.json` 的 8 道题、问题文字和预期法条。前四题需要单部法律中的多个法条，后四题需要跨法律证据。题目不与既有 8 道复合挑战题重复，主要检验“补入新法律”是否既能提高覆盖，又不会把无关法律带入单部法律题。

法条预期核对来源：[《劳动法》](https://www.npc.gov.cn/c2/c30834/201905/t20190521_296651.html)、[《劳动合同法》（2012 修正）](https://jtyst.jl.gov.cn/zw_133208/zcfg/flfg/202211/t20221115_8630061.html)、[《劳动争议调解仲裁法》](https://www.beijing.gov.cn/zhengce/zhengcefagui/qtwj/201912/t20191219_1307906.html)。本项目只导入这三部法律；问题刻意限于其条文能支持的事实，不以题集替代法律意见。

先运行现有 `--decompose` 流程一次，保存各子问题的 Chroma 候选、Reranker Top 5、旧合并规则的最终五条与回答。再对**同一批已保存结果**离线回放旧规则和“新法律优先占一个剩余名额”规则，不重新运行检索或重排。

预先约定的判断维度：

1. 两种规则各有多少题完整包含预期法条；必须逐题报告，不能只看总分。
2. 单部法律题是否混入无必要的其他法律；跨法律题是否出现不适用或相互冲突的法条。
3. 检查旧规则实际生成的回答；若规则改变来源，必须单独核查该变化对回答依据的影响。没有实际生成新规则的回答时，不宣称答案质量得到改善。

这 8 题是独立于上一批实验的新题，但仍是小样本。无论结果好坏，不在本批题上继续调策略；只有来源覆盖与答案依据均可靠，才讨论接入在线链路。
