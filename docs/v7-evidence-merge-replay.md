# V7 最终证据合并：离线回放实验

本实验只读取 `v7-rerank-stage-diagnostic-20260924` 保存的 8 道复合题逐子问题 Reranker Top 5，不调用任何 API，也不改 `CompositeRagChain` 的在线合并规则。

运行：

```text
python -m experiments.merge_replay --run-dir evals/results/v7-rerank-stage-diagnostic-20260924
```

脚本先复现现有“按子问题轮流取法条”规则，并逐题与已保存的最终来源比较；然后回放一个候选策略：各子问题先取第一条，若有剩余名额，优先补入尚未出现在最终来源中的法律，候选间按各自分数相对于本子问题第一名的比例比较；剩余名额继续按原轮流规则填充。最终来源上限始终为 5 条，法条按 `law_id + version + article` 去重。

这批固定记录中，原规则与保存结果 8/8 一致，完整覆盖预期法条 7/8；候选策略完整覆盖 8/8。唯一新增命中是 `probation-wage-holiday-overtime-arbitration`：以《劳动法》第四十四条替换了《劳动合同法》第八十三条，没有挤掉该题其他预期法条。其余七题的预期法条仍被覆盖。

限制：策略是看到这批数据后提出的，8 题不能作为独立验证集；法律多样性不等于法条适用性，某些题还可能包含旧时效等干扰条文。此处只比较来源覆盖，未重新生成回答，也未评审答案的法律准确性。因此结果只能作为下一轮候选，不能据此将策略默认接入 `--decompose`。下一步应先用新题或另一批重排记录验证，再评审最终答案。
