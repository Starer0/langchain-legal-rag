# V8.3 异构资料保留集协议

## 目的

`evals/heterogeneous_cases.json` 已参与了路由、提示词和评测指标的开发，只能反映开发集表现。2026-09-28 起，`evals/heterogeneous_holdout_cases.json` 作为固定保留集，用于一次不再调参的端到端检查。

保留集有 7 题，覆盖指南、纯法条、混合检索和资料外问题。其题目 ID 与问题文本均由测试保证不和开发集重复。预期来源仅指向已进入索引的法律条文或指南章节；评测程序在模型回答完成后才读取这些预期字段，系统运行时不会把它们传入检索、改写、重排或回答提示词。

## 冻结规则

- 不得根据保留集的题目、预期路由、来源、回答或得分修改路由规则、提示词、Chunk、检索、重排或评测指标。
- 若系统发生功能改动，先用开发集迭代；发布候选版本冻结后，再为该版本运行一次保留集。
- 每次运行使用新的 `run-id`。结果位于 Git 忽略的 `evals/results/<run-id>/`，保留原始候选、来源、回答、性能记录和汇总。
- 这是一份项目内的固定题集，不能证明真实用户分布上的泛化能力；后续可增加由独立人员编写、同样冻结的题目。

## 运行

```text
python run_heterogeneous_evaluation.py --run-id v8-holdout-YYYYMMDD --cases-path evals/heterogeneous_holdout_cases.json
```

运行完成后先记录结果，不对当前版本继续调参。下一次产品迭代应使用开发集，并在新的冻结候选版本上重新运行保留集。
