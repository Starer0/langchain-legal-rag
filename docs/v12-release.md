# V12 工程化更新：截至 React 工作区

2026-10-04 将 V11.8 之后已完成并验证的工程化功能统一发布到 main。本次发布覆盖 V12.1–V12.9；后续来源持久化、长期记忆、图与网页整合、任务恢复不包含在本次发布中。

## 已完成

- FastAPI 统一入口：请求编号、结果与耗时日志、轮转，以及 RAG 改写/召回/重排/最终依据阶段记录。
- PostgreSQL：SQLite 迁移工具、对话/消息持久存储、示例账户和资料库等级、登录会话。
- 登录与授权：密码哈希、三天滑动会话、退出撤销、CSRF/来源检查、登录限流、对话归属校验。
- 资料范围：入库资料 A/B/C 标签；服务器按账号允许范围约束向量与 BM25 召回、重排、模型上下文及引用。
- React + TypeScript + Vite：登录、多对话、流式聊天、来源展示、账号切换保护、桌面/平板/手机响应式布局。

CLI 原有图与日期工具学习路径保留。网页目前仍使用原 RAG 服务的流式路径，尚未贯通 LangGraph 的模型流。

## 运行与数据

按 docs/v12-2-postgres-migration.md、v12-3-postgres-web-storage.md、v12-4-account-foundation.md 和 v12-5-web-login.md 准备本地数据库、账户与配置。迁移已有数据前备份，迁移检查与网页账户准备是独立步骤。旧匿名聊天不自动转给新账户。

React 构建见 frontend/README.md：在 frontend 执行 `npm ci`、`npm run build`，根目录本地 `.env` 设置 `WEB_FRONTEND=react`，再启动 FastAPI。源码仓库不包含构建目录；`WEB_FRONTEND=legacy` 保留原静态页面选择。

数据库密码、示例账户凭据文件、.env、HANDOFF、日志、备份、索引、依赖目录与构建产物均不提交。新检出代码需准备本地凭据和数据，不能只检出源码就认为已有本机运行环境。

## 验证

发布前完整复跑：282 Python、23 React、11 Node、5 实际 Chrome 夹具浏览器测试通过，类型检查与生产构建通过。Python 包含临时 PostgreSQL schema，浏览器测试不调用真实模型、不写生产聊天。Python 有两项依赖弃用提示，无测试失败。

此前真实账户登录/历史/退出由代理核验，用户已验证跨浏览器历史同步、账号隔离和资料权限，已认可新界面。真机手机/平板访问尚未验收；校园网连接问题暂不优先处理。

## 后续边界

历史 API 当前只返回角色和正文，来源附件刷新后不能恢复，下一小步计划补齐。后台管理、私有上传、日志查看界面、短期摘要/Token预算、长期偏好记忆、图状态持久恢复、断线重连与自动重试仍按学习计划分步开展。本版本不声称完成所有工程化或 Agent 学习目标。
