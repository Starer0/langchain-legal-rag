# V12.15：账号的核心与扩展记忆

2026-10-07。按已批准的两层设计实现；借鉴 Letta 的分层思路，未引入 Letta 框架。

## 使用

登录后侧栏“长期记忆”打开设置。核心保存简短通用偏好，例如“先给结论，再分点解释，保留法条来源”；有依据的回答每次提供。扩展保存主题背景，用空行分段；回答前按当前问题选择相关条目。点“保存记忆”才生效。开关关闭保留内容；清空后仍需保存。保存失败或版本冲突保留编辑草稿，重新加载会提示放弃未保存内容。

也可单独发“请记住，以后回答先给结论”“以后回答详细一些”“清空核心记忆”。聊天入口与设置修改同一账号记录，保存后重新打开设置或重新加载查看最新值。普通聊天不自动提取记忆。含临时要求、案件日期金额、模糊目标或同时法律提问的命令会澄清。程序要求新内容对应用户原话；删除需要指明旧文本，除少量可验证的详略/语言对立偏好外，替换也需明确旧文本。先结论与详细解释可以共存，不能因调整详略丢失顺序或引用偏好。当前保守识别不是完整自然语言理解，复杂表达可用设置直接编辑。

记忆只影响背景和表达，不是法律来源，也不扩大权限。资料不足仍按原逻辑拒答。扩展检索失败时保留核心，并在答案外显示提示。

## 真实代码与数据流

- `memory_service.py`：校验、段落条目、复用向量、cosine选择、一次受约束模型解析明确命令。
- `memory_storage.py` / `prepare_account_memory.py`：PostgreSQL原文、辅助条目和任务输入；显式加表，不在请求时自动迁移。
- `memory_api.py` / `web_auth.py`：本人GET/PUT，服务端登录身份、CSRF、来源检查、版本冲突、no-store公开投影，不返回向量。
- `web_langgraph.py`：法律流程有依据后进入memory节点再answer；命令独立路由，图只提出修改候选。rewrite/retrieve/rerank不读取记忆；先前记忆命令不进入后续改写历史。
- `generation_tasks.py`：完成时按冻结请求与记忆重新校验有界操作及候选文本；同一事务提交记忆、问答反馈、来源与completed；代次及revision防旧执行/旧页面覆盖。成功不提前stream。
- `recovery_runner.py`：接受任务时固定输入。完成图恢复补保存，不重做已完成记忆处理；任务已completed重放不再次修改。
- `frontend/src/MemorySettings.tsx` / `useMemory.ts`：独立设置草稿与身份隔离，旧账号迟到请求不能覆盖新账号；保留原聊天与后台任务操作。

## 预算、调用与边界

核心最多1500字符且500估算token；扩展最多12000字符、40段、每段1000字符；回答最多3段且500估算token。使用cl100k本地估算，不能当作提供商计费token。限制集中在MemoryLimits；相关性起点0.5可通过MEMORY_SIMILARITY_FLOOR修改，不是概率、最优或已校准阈值。

向量使用现有远程embedding服务，存入PostgreSQL，应用内比较；不是本机生成，也不使用法律Chroma索引或pgvector。只对新/变更段落批量生成。纯核心更新、清空或相同条目修改开关不重新生成向量。普通问答仅在启用且扩展非空时增加一次query embedding，不新增聊天模型选择调用；明确命令增加一次解析模型调用。embedding8秒、命令20秒SDK超时，max_retries=0；原法律模型配置保持既有行为。

正常运行任务使用启动版本；设置修改影响下一次提问。服务重启后若记忆版本/开关变了，未完成图中断并提示重发，避免再次读取已删旧记忆；已完成图可补保存原回答。清空当前记忆不会擦除旧回答、历史检查点或备份；任务快照/检查点随删除对话走既有清理流程。

短期上下文仍是最近4轮等既有策略，本次未加入摘要、自动记忆提取、风格预设、额外工具、多实例或自动失败重试。共享CLI不自动获得账号记忆。

## 验证与可量化记录

自动测试使用本地假模型/向量与真实临时PostgreSQL，未调用付费模型或写生产测试聊天。覆盖两账户、CSRF、CAS、超限、保存失败保留旧记录、清空/关闭、相同向量复用、相关与无关背景、日志不含完整私人记忆、无依据拒答、图恢复、代次、完成事务回滚、设置身份切换、桌面与375px布局。

可复述的机制证据：相同扩展段落只生成一次向量，后续核心修改不再调用embed_documents；扩展为空/关闭时query embedding调用为0；普通问答记忆选择额外聊天模型调用为0；已完成命令图恢复时解析调用保持1次、revision只增加1、反馈只保存一对消息。均为测试夹具计数，不是生产成本改善百分比。
