## 行为与设计

网页新图为 `web-rag-model-memory-v1`：上下文准备后，每条输入执行一次 understand，原生工具响应包含一个 `plan_answer` 和至多一个 `update_memory`。法律路线直接使用该次生成的检索改写，不再独立调用旧 rewrite；纯偏好、一般回复及澄清不会检索法律资料。混合消息分别处理法律问题与记忆更新。旧 CLI 和旧图调用者保持兼容。

前台和后台共用 `MemoryTools.prepare/commit`。模型负责理解含义、判断重复/补充/冲突；程序核对真实持久输入、账号、目标、revision、policy epoch、预算与索引。prepare 不提交；前台 generation 完成事务或后台 job apply 事务提交文本、原子条目、证据和回执。混合回答中的记忆提交使用 savepoint，失败不会丢失法律回答。冻结决策先落库，恢复复用工具参数，不重新让模型生成另一组更新。

开放文本可保存偏好、本人背景或学习主题，不固定“结论/分点/例子”白名单。duplicate 保持原文字并追加证据；complement 保留旧内容，另存 delta，通过来源证据保留补充的依据。手动与旧版段落受保护。冲突替换、删除、清空需要设置界面确认。推测学习主题须至少两个不同用户轮次，只进入扩展记忆待确认建议；确认后仍保留 inferred 标记与原始证据。同文同操作的待确认建议合并来源。

自然表达受后台自动积累开关控制；用户明确要求新增可在自动积累关闭时保存。临时表达要求仅影响本轮。后台继续空闲约120秒或压缩触发，一次原生工具调用回顾，90秒上限；前台20秒上限，均可配置。模型没有自动重试。核心500估算token/1500字符；扩展12000字符/40段/每段1000字符；后台新来源4000、前文1000估算token。

新 API 提供来源、归纳文字、声明或推测、时间与保护状态；完成回执区分 saved/noop/suggested/blocked/conflict。刷新读取持久结果，pending 不称已保存。删除对话保留已保存摘录并去掉消息定位；手动删除退休条目时清除内容和证据，忽略/失效建议清除候选内容。法律摘要使用语义路线：纯偏好排除、混合消息取 legal_question；理解和回顾仍可读取授权原文。

## 复现与配置

离线默认不调用模型：

```powershell
D:\conda\python.exe scripts/evaluate_model_memory.py --output logs/model-memory-work/offline.json
D:\conda\python.exe scripts/evaluate_model_memory.py --model-results logs/model-memory-work/provider-full.observations.json --legacy-routing-baseline --output logs/model-memory-work/comparison.json
```

显式 `--collect` 调用新版真实模型，`--collect-legacy` 调用旧记忆解析方案；`--case mixed` 可限制样例。报告记录模型、参数、时间、调用数、usage、原生工具名称和时延。结果位于被忽略的本地 logs，不输出密钥或真实记忆。
