# V12.11：生成回答时浏览其他对话

此前全局 busy 和操作锁同时禁用了侧栏与发送，用户需要留在正在回答的对话。现在生成回答时仍可选择其他已有对话浏览，原请求继续接收流式事件，侧栏原对话显示转圈；返回时显示已有进度，后台完成后重新读取保存的回答和来源。

前端新增 runningConversationId 和按对话ID保存的临时生成视图。流归属只依赖客户端与账号版本，不再依赖当前选中对话；事件仅更新本次请求所属对话，只有正在查看它时才更新消息面板。切换历史仍用选择版本挡住迟到响应，账号变化/卸载清空临时视图并取消旧请求。

后台失败移除不完整回答，保留原问题与请求编号，切回原对话可查看；不会把失败提示或草稿放进正在浏览的另一对话。成功视图用完清理，历史从数据库重新读取，不保留整套成功消息缓存。

## 第一版范围

本步仅允许生成时查看其他对话。仍一次生成一条回答；生成期间新建、重命名、删除、退出和再次发送保持禁止，另一对话输入区显示可先浏览历史的提示。刷新/关闭网页、网络断开后的可靠继续未新增，仍属于后续后台任务生命周期与持久恢复设计。

没有后端或数据库变更，React重新构建后原8001服务直接提供新产物。历史来源持久化小步此前已由用户刷新验收，本次不会改变快照数据模型。
