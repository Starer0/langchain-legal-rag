# V8.2：多对话 Web RAG

V8.2 将 V8.1 的单一浏览器历史升级为多个独立对话。每个浏览器仍由匿名
Session Cookie 标识；Cookie 不包含聊天内容，只用于服务端找到该浏览器的对话。

## 已实现能力

- 左侧栏展示当前浏览器的历史对话，按最近更新时间排序；
- 新建对话、切换对话、手动改名与带确认提示的永久删除；
- 每段对话独立保存短期历史，因此 History-aware Rewrite 不会读取其他对话；
- 首次成功回答后，以用户问题自动生成简短标题；手动改名后不再覆盖；
- 流式回答进行时锁定侧栏操作，避免切换对话导致写入错位；
- V8.1 的旧历史会在首次启动 V8.2 时迁移为“已迁移的对话”。

## 本地启动

```powershell
python -m uvicorn web_app:app --host 127.0.0.1 --port 8001
```

在浏览器打开 `http://127.0.0.1:8001/`。端口 8000 在部分 Windows 环境会被
系统保留，使用 8001 更稳妥。

## 当前边界

V8.2 当时使用 SQLite 与匿名 Cookie。V12 已增加 PostgreSQL 存储并切换本机配置，
匿名 Cookie 继续用于浏览器隔离；账户与登录会话仍待后续实现。
当前启动与验收说明见 [网页后端接入 PostgreSQL](v12-3-postgres-web-storage.md)。
