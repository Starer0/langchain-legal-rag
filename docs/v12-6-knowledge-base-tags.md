# V12：资料所属库与片段标签

本步先给资料及其切分片段登记所属资料库，为后续按账号等级检索准备数据。用户确认的演示分组为：

- A：《中华人民共和国劳动法》，107 条。
- B：《中华人民共和国劳动合同法》，98 条。
- C：《中华人民共和国劳动争议调解仲裁法》54 条，以及仲裁办事指南 21 段，共 75 个片段。

`data/laws.json` 和 `data/guides.json` 每份资料必须填写 `knowledge_base_id`。这是一个不带空白的标识，首字符为英文字母，其后允许字母、数字、下划线和连字符，总长度最多 64。以后资料库可以使用其他标识；本次 A/B/C 是演示配置。

`corpus_metadata.py` 提供共同校验；`legal_corpus.py` 将登记标签写入每个法条片段，`guide_corpus.py` 保留指南登记中的标签。切分内容、页码、文档类型、法律 ID、版本等仍保留。缺失、空值或非法标签拒绝入库，直接调用切分器也会检查。

目录和索引结构共同参与指纹；索引结构版本更新为 `v12-knowledge-bases-1`。标签调整会产生新的索引版本，旧索引不会被覆盖。Manifest 的来源清单记录所属库。入库复用、发布和启动读取都核验实际片段标签是否与来源 ID、版本、文件和登记标签一致；标签错误时拒绝使用或发布，保留已发布 Manifest。
