# 网页问答接入 LangGraph

网页问答工厂现在返回 `LangGraphStreamingRagTurn`。后台任务仍负责接收问题、保存进度和完整问答；图负责本次问答内部的步骤顺序。

## 执行路径

`START → rewrite → retrieve → rerank → answer → END`。服务器确认的资料范围内没有依据时，重排后转到 `no_evidence`，返回既有提示，不调用回答模型。

`web_rag.py` 保留共享的改写、检索、重排、回答方法与顺序执行版本；`web_langgraph.py` 用真实 StateGraph 组织这些方法。每次调用创建独立 State、权限范围、计时和日志对象，同一张编译后的图可服务不同账号的请求。`rag_app.py` 的 `create_web_rag_turn` 选择图实现。

回答节点通过 custom 流交付既有 status/delta 事件。内部 State 和改写模型的 token 不交付网页；图正常结束后才发 done，原后台任务再按既有事务保存问答和来源。模型失败不会交付成功完成事件。关闭流会等待当前同步计算结束并检查取消标志，取消阶段记为失败；浏览器刷新在任务模式下只停止观察，不关闭后台图执行。

## 保留的功能与边界

登录、服务器资料授权、召回过滤、重排来源核验、请求编号及阶段日志沿用原实现。React、PostgreSQL、后台任务和来源快照接口不变，无需本次数据库迁移。CLI 学习图保持独立。

本步没有新增工具、人工补参、检查点、长期记忆、后端重启续跑或自动重试。任务表保存部分回答，不代表 LangGraph State 已持久化。

## 验证

323 项 Python 测试通过（含临时 PostgreSQL），2 项依赖弃用警告。图测试覆盖节点和边、旧行为一致性、首段提前到达、异常无 done、取消日志、同图并发账号隔离、权限过滤与阶段日志。10 项 Chrome 浏览器测试通过；后台刷新夹具使用真实图和本地阻塞假模型，验证 1440/375px 刷新、关闭重开、切换聊天、完成后来源恢复和单次模型调用。

独立审查复现取消末尾的日志缺口，新增失败测试后修复并完整回归。新版本机服务首页、三个示例账号登录/历史/任务模式/退出通过。未调用真实远程模型，未创建生产测试聊天；真实模型问答仍待用户验收。本步不自动提交或推送。
